# Unidad I — Árboles Binarios

- `abb-estatico.py`: Implementación de un Árbol Binario de Búsqueda (ABB)
  usando arreglos.
- `abb-dinamico.py`: Implementación de un Árbol Binario de Búsqueda (ABB)
  usando nodos enlazados por referencia.
- `arbol_expresiones/`: Conversor de expresiones infija a prefija/postfija
  construyendo un árbol de expresión (no un ABB) y obteniendo el resultado
  mediante los recorridos preorden y postorden. Aplicación con interfaz
  gráfica en Flet, estructurada bajo el patrón MVC.
