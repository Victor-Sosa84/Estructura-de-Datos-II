# Unidad I — Árboles Binarios

- `abb-estatico.py`: Implementación de un Árbol Binario de Búsqueda (ABB) usando arreglos.
- `abb-dinamico.py`: Implementación de un Árbol Binario de Búsqueda (ABB) usando nodos enlazados por referencia.
- `abb-numeros.py`: Implementación de un Árbol Binario de Búsqueda balanceado (AVL), con operaciones de inserción, búsqueda, eliminación y recorridos preorden, inorden, postorden y por niveles.
