# Proyectos

En esta carpeta se encuentran los proyectos desarrollados durante la materia **Estructura de Datos II**.

## Contenido

- **[Grafos](./grafos/):** Implementación de grafos, recorridos BFS y DFS, y algoritmos de Kruskal y Dijkstra.
- **[Machine Learning](./proyecto-machine-learning/):** Implementación del juego Tres en Raya utilizando técnicas de aprendizaje automático.
- **[Árbol de expresiones](./arbol_expresiones/):** Representación y recorrido de expresiones mediante preorden (notación polaca), inorden (notación infija) y postorden (notación polaca inversa). Aplicación con interfaz
  gráfica en Flet, estructurada bajo el patrón MVC.
